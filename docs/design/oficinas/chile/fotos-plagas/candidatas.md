# Fotos de las 6 guías de plagas · candidatas de Wikimedia Commons (6-nov-2026)

Regla (Roger, 6-nov-2026): fotos reales de la especie o IA bien hecha. En Commons, dominio público o CC0; si solo hay CC BY,
como con el hantavirus, con el crédito en la ficha. CC BY-SA no entra. Hoja de contactos (local, no va a git):
`hoja-candidatas-2026-11-06.jpg`. Búsqueda por la API de Commons con el nombre científico de cada especie (y «feral
pigeon», «rock dove», «Columba livia domestica» para la paloma), filtrando por licencia. **Nada se pone hasta que Bryam elija.**
